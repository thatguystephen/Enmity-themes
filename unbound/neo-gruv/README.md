# Neo Gruv for Unbound

The Neo Gruv Enmity theme (`NeoGruv.json` in the repo root), ported to Unbound's theme format and Discord's current colour tokens.

## Install

1. In Discord, open Unbound settings, then **Design**, then **Themes**.
2. Tap **+**, then **Install from URL**.
3. Paste `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/neo-gruv/manifest.json`.
4. Tap the theme, then **Restart**.

## Changes from the Enmity version

- Hover and long-press highlights are a 16% gold tint instead of solid gold, so the text stays readable.
- Channel icons use the theme's gruvbox grey `#928374`; the original `#4C4C4C` was nearly invisible on `#2A2A2A`.
- Dropped: the light-theme column (Unbound themes are one palette), the scrollbar and keyboard colours, and the `plus` icon tints.
