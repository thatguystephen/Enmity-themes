# System24 for Unbound

The System24 Enmity theme (`system24.json` in the repo root), ported to Unbound's theme format and Discord's current colour tokens.

## Install

1. In Discord, open Unbound settings, then **Design**, then **Themes**.
2. Tap **+**, then **Install from URL**.
3. Paste `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/system24/manifest.json`.
4. Tap the theme, then **Restart**.

## Changes from the Enmity version

- Icons use `#808080`; the original's `INTERACTIVE_NORMAL` `#1A1A1A` would hide them on the background.
- Buttons use `#1A1A1A` so they show against the `#121212` background; the chat box stays borderless as in the original.
- Dropped: scrollbar, spoiler, swipe-to-reply and keyboard colours (no current token) and the `plus` icon tints.
