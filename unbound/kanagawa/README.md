# Kanagawa for Unbound

The Kanagawa Enmity theme (`Kanagawa.json` in the repo root), ported to Unbound's theme format and Discord's current colour tokens.

## Install

1. In Discord, open Unbound settings, then **Design**, then **Themes**.
2. Tap **+**, then **Install from URL**.
3. Paste `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/kanagawa/manifest.json`.
4. Tap the theme, then **Restart**.
