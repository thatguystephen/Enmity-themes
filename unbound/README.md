# Unbound themes

These are the Enmity themes from this repo, ported to [Unbound](https://github.com/marioparaschiv/unbound). To install one, open Unbound settings → **Design** → **Themes** → **+** → **Install from URL**, paste its link, then tap the theme and **Restart**.

| --- | --- |
| Kanagawa | `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/kanagawa/manifest.json` |
| Date Night | `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/date-night/manifest.json` |
| Neo Gruv | `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/neo-gruv/manifest.json` |

| System24 Rose Pine | `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/system24-rose-pine/manifest.json` |
| You Blue | `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/you-blue/manifest.json` |

Each folder's README lists what changed from the Enmity version. The Trakya font snippet isn't here: Unbound installs fonts as single font files.
