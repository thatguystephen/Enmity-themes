# System24 Rose Pine for Unbound

The System24 Rose Pine Enmity theme (`system24-rose-pine.json` in the repo root), ported to Unbound's theme format and Discord's current colour tokens.

## Install

1. In Discord, open Unbound settings, then **Design**, then **Themes**.
2. Tap **+**, then **Install from URL**.
3. Paste `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/system24-rose-pine/manifest.json`.
4. Tap the theme, then **Restart**.

## Changes from the Enmity version

- Mentioned messages use a 30% rose tint instead of 85%, which made the light text unreadable.
- Message hover is a 10% white tint instead of 30%, for the same reason.
- Kept: green `#9BBB59` as the danger colour, as in the original (it swaps red out).
- Dropped: scrollbar, spoiler and swipe-to-reply colours and the `plus` icon tints.
