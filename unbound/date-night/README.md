# Date Night for Unbound

The Date Night Enmity theme (`DateNight.json` in the repo root), ported to Unbound's theme format and Discord's current colour tokens.

## Install

1. In Discord, open Unbound settings, then **Design**, then **Themes**.
2. Tap **+**, then **Install from URL**.
3. Paste `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/date-night/manifest.json`.
4. Tap the theme, then **Restart**.

## Changes from the Enmity version

- Sheets and modals use `#141414` (the theme's old `PRIMARY_6xx` sheet colour) so they stand out from the black chat.
- Message long-press highlight is a 16% pink tint instead of solid pink, so the text stays readable.
- Dropped: the scrollbar and keyboard colours (no mobile token), and the `rosiecord-plumpy` icon pack (install an Unbound icon pack separately).
