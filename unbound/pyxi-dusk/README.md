# Pyxi Dusk for Unbound

The Pyxi Dusk Enmity theme (`PyxiDusk.json` in the repo root), ported to Unbound's theme format and Discord's current colour tokens.

## Install

1. In Discord, open Unbound settings, then **Design**, then **Themes**.
2. Tap **+**, then **Install from URL**.
3. Paste `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/pyxi-dusk/manifest.json`.
4. Tap the theme, then **Restart**.

## Changes from the Enmity version

- The original recoloured Discord's old `PLUM_*` greys, which Discord no longer uses; each grey is now pinned to the surface it used to paint.
- Links use the light purple `#B09ACD`; the old link colour `#624779` was unreadable on the dark background.
- Fixed the `##c666ff14` typo in the mention colour. Online, DND and offline keep Discord's colours, as before.
- Dropped: the `Solar` icon pack (install an Unbound icon pack separately) and the `plus` icon tints.
