# You Blue for Unbound

The You Blue Enmity theme (`YouBlue.json` in the repo root), ported to Unbound's theme format and Discord's current colour tokens.

## Install

1. In Discord, open Unbound settings, then **Design**, then **Themes**.
2. Tap **+**, then **Install from URL**.
3. Paste `https://raw.githubusercontent.com/thatguystephen/Enmity-themes/main/unbound/you-blue/manifest.json`.
4. Tap the theme, then **Restart**.

## Changes from the Enmity version

- Left out the test colours in the original (`#00ff00`, `#ff0`, `#ff00ff` in the chat box, badges and raw ramps).
- Selected rows use the theme's 16% blue (`BG_MOD_SUBTLE`) instead of the stray 4% green.
- Dropped: the `MaterialTwoTone` icon pack (install an Unbound icon pack separately), polls colours, and the `plus` icon tints.
